# Nuphy Air75 黛粉轴

> 已卖，2025年12月22日购买 539 入手，2025年12月26日原价出

## 动机

1. 蹲了很久，价格从 679（京东） -> 539（抖音），价格便宜；
2. 工位和宿舍各需要一把键盘，来回背有点不现实；

### 爽点

1. 静音，黛粉声音几乎没有；
2. 相比于 [Keychron Z7Max](./keychron-z7max.md) 的手感要轻松很多；
3. 键帽不容易翻车了，稳定性好了一些；
4. 2.4G 接收器终于可以收纳到机器内部了；

### 不爽的点

这代的设计了抛弃了太多东西，真是把前两代的家底败光了：

1. QMK 开源固件；
2. 更低压力系数的轴体；
3. 防尘罩（力推自己家的保护套）；
4. 老婆贴纸；
5. 增补轴；
6. 重量；

最后换来了什么：

1. 因为填充材料，变得更重了，声音实打实的好了一点；
2. 没有塑料防尘罩；
	1. ~~可能是V3自定义高旋钮不太好做壳;~~(Node75 也没有，这是刻意的削减)[^kai-xiang]
	2. 可能是推销自家的保护皮套（100+）；
3. 轴体与前两代完全不一样，无法通用；
4. （没有遇到但是网上吐槽比较多的点）品控，这个轴体永久了会连发，需要换轴处理，网上的评论非常多，针对于戴粉轴这个轴体 [^ghost-click]

## 手感

键程是要稍微长一点，敲下去触底也有肉肉的、软硅胶反馈的感觉，说不上喜欢，相对的，压力上可以明显感觉出比芦荟轴重，按不到底，有点逼死相迫症，也说不上讨厌，还可以吧。

静音是真静音，闷声也不错，做工也好看，一切还好。

然后就是下一个破防的时刻，就是我不知道他左右两侧的进度条有任何的作用，我盲打的时候是不看键盘的，所以灯条的律动就是给别人看的？单纯的炫技？

然后，这一代快捷键又全换了！！！我根本不知道怎么关掉这个白色的进度条。

最后我不理解为什么这一代不给其他轴的样轴了，这很可惜你知道吗？我完全不知道其他轴体的手感，除非我还要购买他家昂贵的配件。

最后还是想要退掉了，还有最崩溃的原因，键盘他是消耗品，他几个月甚至一年之后价格要跌差不多一半，想想我的 [V2](./nuphy-air75-v2.md) 当时买来 550 多，用了一年，现在差不多只能卖 350 左右，但你要知道原价可是 600、700 哦？整整一年，跌了一半多，V3 毫不意外也会遵循这个规律，而我对身边有个第二吧键盘还不是刚需，所以我还是会考虑退掉。（我的老键盘挂闲鱼无人问津也是一个动机）

## 其他想法

### 价格

标价 799，打折 679，双十二抖音官旗 599，第三方店铺返佣金 530，但都没有黛粉轴，最后没有入手，我非常震撼这个键盘的利润空间，就算是 530，官方依然有的赚，如果真的原价 600～700 入手，那真的是亏大发了。

最近在盯盘的过程中，发现这个轴体的键盘也是经常性没货，需要等商家补货，我不清楚这个产能怎么样，但推测来看，说不上好。

最重要的，我说不上除了做工，前高之外，任何关于 AirV3 和 Node75 之间的区别。

好在后者还是勉强能拆的，AirV3 严丝合缝就趁早放弃吧。

### 轴体原因

下面这个评论不知道出自那个视频的评论区了，放在这里

> 我不是黑 我那把可能是中奖了 被我退了 我给你总结一下主要的问题：
> 1.退格键敲左边有打在钢板上的那种哒哒哒的声音 但是敲中间 右边没有
> 2.有 1/5 差不多的轴体有异响 是一种我在其他任何键盘上都没听到过的一种高频异响 而且是不是按下而是释放过程中的响声 打着打着出来几声这种声音比较影响输入体验
> 3.轴体声音的一致性做的很差（虽然静音轴要求声音不太合理）有些轴敲起来是沙沙声 个别几个听起来都快像红轴了 声音完全不一样
