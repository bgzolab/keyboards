# Nuphy Air96 V1

> 已卖，676入手，350转手

1. 用 K380 腱鞘炎
2. 96 和 75 价钱差不多，但是多一个小键盘

## 快捷键

- 侧灯：`FN + ? + ∧ / ∨ / < / >`
- F 键功能切换：` FN + X + F`
- 睡眠模式：`FN + X + C/V`
	- 闪绿灯 => 开启
	- 闪红灯 => 关闭
	- 下适用
