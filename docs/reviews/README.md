## Timeline History

一开始就是给平板电脑配置的 [K380](./logi-k380.md)，后来慢慢在电脑上也用了起来；

中途按的太多，出腱鞘炎了，考虑用薄膜久了，不想加掌托，在搞矮轴之间，选择了前高做工更低的矮轴，选了当时社区推荐的天花板 [Nuphy96](./nuphy-air96-v1.md)；

后来发现 96 的布局有点太笨重了，不好携带，忍痛卖了换 75 配列；

公司用一把，家里面有小主机，调试东西的时候没有键盘非常麻烦，所以买了把二合一薄膜键盘 [K400Plus](./logi-k400p.md)；

后来一段时间后发现这玩意坏掉了，只能考虑再换一把矮轴机械，最后挑了 [Z7Max](./keychron-z7max.md)，但是红轴对我来说还是有点重了，个人有点肌无力，按着太累了，而且我自己触发过好几次睡死 BUG，最后也出掉了；

2026年双11买了第一把高轴键盘——Rainy75V2，做工声音没得说，但是唯独Mac 驱动把我劝退了，因为我觉得它大概率未来不会改，最后也 7 天无理由退掉了；

### Now: 静电容？

在考虑要不要买一把静电容键盘退烧算了，在看 NIZ 87 三模，NIZ 的续航只有一个星期不到，很纠结；现在感觉 [Air75V2](./nuphy-air75-v2.md) 真是巅峰之作，支持开源固件，有芦荟轴，还送防尘罩，[V3](./nuphy-air75-v3.md)把这些全砍了；

> 静电容的价格都那样，硬件物理成本决定的。
而且静电容还有个劣势：因为其是靠半球弹簧+胶碗支撑，所以手感是会劣化的（虽然没有薄膜劣化的那么快）。
静电容最明显的优势：触发距离可调，因为没有物理接触，所以手感可以做的很轻。
所以还是理性决策吧。如果想要一个灵敏触发且轻的键盘，那么静电容非常合适。
