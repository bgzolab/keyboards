# 一些心得

用过的键盘我会专门建一个文档，没有真实用过的，就放在这里：

## Now

在考虑要不要买一把静电容键盘退烧算了，但是看测评，NIZ 的续航只有一个星期不到，还是很纠结；

现在感觉 Air75V2 真是巅峰之作，支持开源固件，有芦荟轴，还送防尘罩，V3把这些全砍了；

## Perferance

> [!NOTE]
> 1. 我对声音没太多偏好，更倾向实用主义，就跟我从薄膜切到机械是为了缓解自己手指疼痛一样；
> 2. 键盘触发原理大致分为：静电容、霍尔、机械、薄膜，目前我只用过后两个；

用久了 Nuphy，有了这样的体会：

1. 可维护性，矮轴可玩市场真是太差了；
2. 配件，砍了芦荟轴，砍了防尘罩，力推自己家的保护套，砍了开源固件，也砍了老婆贴纸，Nuphy 真是把前两代的家底败光了；
3. 压力系数一定要 30-40 之间，超过40 的谨慎购买，压力太大了
4. 铝坨坨，只要上铝，做工一般都没得说，Nuphy 还只给你用上盖，抠门的要死；
5. 适配 Mac 键盘布局，直接放上去就可以用；

## Personal History

一开始就是给平板电脑配置的 K380，后来慢慢在电脑上也用了起来；

中途按的太多，出腱鞘炎了，考虑用薄膜久了，不想加掌托，在搞矮轴之间，选择了前高做工更低的矮轴，选了当时社区推荐的天花板 Nuphy96；

后来发现 96 的布局有点太笨重了，不好携带，忍痛卖了换 75 配列；

公司用一把，家里面有小主机，调试东西的时候没有键盘非常麻烦，所以买了把二合一薄膜键盘 K400Plus；

后来一段时间后发现这玩意坏掉了，只能考虑再换一把矮轴机械，最后挑了 Z7Max；

但是红轴对我来说还是有点重了，个人有点肌无力，按着太累了，而且我自己触发过好几次睡死 BUG，最后也出掉了；

后来公司里面就不用自己的键盘了；
