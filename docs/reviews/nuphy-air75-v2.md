# Nuphy Air V2

[Nuphy Air96 V1](./nuphy-air96-v1.md) 太重太长了，方向键不好识别，最终出了换 75 布局。

## 快捷键

- 侧灯：`FN + M + ∧ / ∨ / < / >`
- 睡眠模式：`FN + ]`

因为 VIA 的支持，不支持 FN Lock

## 优点

拿到手的第一感觉就是：75 比 96 真是好用多了，即使是牺牲小键盘但依然值得；

1. 盲打定位方向键；
2. 直接放在笔记本键盘上使用
3. 通勤方便

所以到手后直接把 96 的键盘挂在了二手市场卖掉了。
