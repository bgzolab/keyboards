# 活该你们矮轴市场不景气没销量: 洛斐小顺flow2和NuPhyAirV3使用体验

UP 主自费买了 NuPhy Air75 V3（字幕误作"路飞"）和洛斐小顺 Flow2（字幕误作"洛菲"），结果一把退货、一把哑炮，由此怒喷矮轴厂商：市场不景气不是需求问题，而是产品只做了设计、没管落地和品控。

## 视频脉络

### 0. 开场：火气从哪来

- 情绪铺垫：憋了一晚上才录，因为晚上说话声音小、发泄不出来。
- 核心论点：厂商总说自己"做矮轴不赚钱、市场小、生不逢时"，实际是半吊子技术加不用心，不是市场的问题。
- 声明：不是要拉黑品牌，而是希望厂商听用户反馈；做得好照样会买、会出视频推荐。

### 1. 背景：两轮矮轴经历

- 第一轮：买过洛斐小顺一代、一代青春版及京造等几把，小顺一代是当时的第一名，内胆声音、外壳工艺都好，打破了他对洛斐"只会做样子货"的刻板印象。
- 第二轮（本次）：一直蹲某款没发布的矮轴，蹲不到，只能从现售产品里挑，先买了 Air75 V3，退货后换了小顺 Flow2。
- 怒气曲线：下单前 20% → Air75 V3 到手 90% → 小顺 Flow2 到手 110%，最终决定放弃恰饭、发骂人视频。
- 铺垫：Air75 V3 的差评他原本没打算公开，是 Flow2 的轴体问题成了"压垮骆驼的最后一根稻草"。

### 2. NuPhy Air75 V3：罪孽深重的那把（已退货 + 超长差评）

- **旋钮**：不支持热插拔更换；阻力极大、没有阻尼感只有"阻"，像里面掺了泥；单指转不动，高版旋钮要掰到担心掰断；位置在边角，旁边键帽还挡手。
- **轴体**：2026 年了还这么"钝"，行程一卡一卡，按一次能卡三次；对比橘子银轴 V2（键程同为约 3.0mm）顺畅度差一个档次；上盖音碎、磕碰音多且锐利，油给得厚（防尘壁旁溢出）却依然又钝又炸。
- **外壳**：600 多元、大配列 700 多，却是半铝——上盖铝、底壳塑料，铝上盖极薄（不到普通键盘上盖的一半）；阳极工艺甚至不如 200 元级早期维咖 Lucky。对比同价位麦丛 A468GT（磁轴、客制化级阳极）。
- **大键**：已不是钢丝音范畴，按空格两侧直接"哑炮"，发不出正常轴体触底声，只有硅胶触底般的闷响，大键根本没法正常使用。
- **拆装**：轴体尺寸非标，常规拔轴器对不上，只能逐个掰卡扣，没法方便地调大键、洗轴重润。
- **宣传落差**：评测视频只说"能插高轴"，实际因矮轴内胆和针脚都短一截，高轴只能勉强插进针脚触发，卡扣完全卡不进、装不稳；且针脚位置与标准机械轴不同。
- **结论**：底子太差，不值得改造，退货。

### 3. 洛斐小顺 Flow2：压垮情绪的最后一根稻草

**预期外的优点**

- 右侧多出来的一块实际只有约 2U，比宣传图和想象中小很多，不怎么碍事。
- 全铝机身，500 多元价位，阳极工艺丝滑，达到客制化键盘水准（明显好于 Air75 V3）。
- 键帽指尖接触面积加大，减少误触，码字体验好；矮轴本身声音不占优，内腔大一点无所谓。
- 设计细节：灯窗与定位板/壳体/键帽配色统一；脚撑下藏开关；触控条灵敏；90 度弯头编织线带镀层；整体简约干净。

**缺点**

- 体积超出预期：侧边高度 13mm 多，比 Air75 V3 还高，和某些高轴键盘只差 2-3mm，作为矮轴"便携"意义被削弱。
- 侧面漏轴；背板光秃秃，外观设计不如一代（一代脚撑、背面更有设计感）。
- 内胆素质一般，没有因为机身更厚而变好，谈不上铝坨坨那种集中的声音。
- **致命问题：原装轴大面积哑炮**。触底像胶粘住，一堆哑炮里夹一个正常的；上盖音炸、杂音碎。把轴装到试轴板上复现，确认是轴体本身的问题，不是内胆或装配问题。
- 处理方式：不退货，因为矮轴市场"没得选"，准备自己换轴改造。

### 4. 行业批评：活该没销量

- **兼容性自杀**：每家矮轴针脚/轴体规格都要搞特殊、互不兼容，用户买了一套就玩不了别家轴，直接把路人推走。建议统一按标准高轴针脚位置来做。
- **价格与体验不匹配**：五六百到六七百的矮轴，内胆一般、问题一堆、还不兼容；同样键程（约 3.0mm，相当于银轴）下，橘子银轴、阿佩罗装在高轴内胆里素质好几个档次。
- **用户会用脚投票**：既然矮轴又贵又不好用又不兼容，追求便携的用户不如几十到一百块买把薄膜，轻薄、免充电、不心疼。
- **力气用错地方**：与其研究针脚特殊化、标榜自己独特，不如把哑炮、上盖音、磕碰音、行程卡顿这些基础问题解决——"轴得有个轴样"。
- **时代对比**：2026 年惠木星、旭华等轴厂都在卷，矮轴却还在原地搞这些花样。

### 5. 结语与呼吁

- 两家公司的设计、理念、零配件、操作逻辑都能看出用心，问题出在"落地"环节：大键调校、轴体品控、旋钮阻尼、阳极量产工艺，像是只玩过样品、没摸过大货。
- 恨铁不成钢：本来可以让他自费出两个夸的视频，结果换来一个骂的视频。
- 对厂商：设计做好的同时把成品核实一遍、把品控拿捏住；有改进进度或难言之隐欢迎发在评论区。
- 对观众：求推荐真正好用的矮轴键盘和矮轴轴体，他想玩但"没得玩"。
- 收尾：希望大家共勉、一起改进，"这里是一木先生"。
